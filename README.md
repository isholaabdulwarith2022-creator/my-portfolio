## Running Locally

Create a virtual environment, install the requirements, and run the Flask application with:

`py app.py`

The website will be available at `http://127.0.0.1:5000`.

## Deployment

The application includes Gunicorn for production deployment on platforms such as Render.

Production start command:

`gunicorn app:app`
